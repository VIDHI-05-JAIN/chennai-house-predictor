# 🏡 Chennai House Price Predictor

A machine learning web app to predict house prices in Chennai.

## 🔗 Live Demo
[Click here to open the app](https://chennai-house-predictor-2cimvyfrcjbho7tb4hpnva.streamlit.app/)

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy
- Plotly

## 📁 Project Structure
chennai-house-predictor/
├── app/app.py        # Main Streamlit app
├── model/            # Trained ML model
├── data/             # Dataset
└── requirements.txt  # Dependencies
